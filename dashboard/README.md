# Panel de Contenido

Dashboard de operación de contenido construido con [Next.js](https://nextjs.org),
Tailwind CSS y componentes shadcn/ui (escritos a mano). Ver `CLAUDE.md` para el
detalle completo de la arquitectura y las decisiones tomadas.

## Cómo correrlo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en el navegador.

## Otros comandos

```bash
npm run build   # build de producción
npm run lint    # linting con ESLint
```
