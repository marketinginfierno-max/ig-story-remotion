# Tipos de gancho para videos cortos (Reels / TikTok / Stories)

Referencia rapida de tipos de gancho (los primeros 1-3 segundos de un video) para usar al planear guiones y contenido.

## Gancho de pregunta

Abre con una pregunta directa que el espectador quiere ver respondida.
Ejemplo: "¿Sabes por que tu pan no queda esponjoso?"

## Gancho disruptivo

Interrumpe el patrón esperado con algo visual o verbal fuera de lo común (movimiento brusco, frase inesperada, corte agresivo) para frenar el scroll.
Ejemplo: gritar/susurrar algo inusual, tirar un objeto, empezar a mitad de una acción.

## Gancho contraintuitivo

Contradice una creencia comun o "lo que todos hacen", generando curiosidad por el porque.
Ejemplo: "Deja de lavar el arroz antes de cocinarlo."

## Gancho de resultado

Muestra primero el resultado final (el "después") para generar interés en como se llegó ahí.
Ejemplo: enseñar el plato terminado o la transformación antes de explicar el proceso.

## Gancho tutorial

Promete enseñar algo concreto y accionable desde el primer segundo.
Ejemplo: "Así se hace la salsa en 3 pasos."

## Gancho negativo

Señala un error, un problema o algo que se está haciendo mal.
Ejemplo: "Estás arruinando tu carne si haces esto."

## Gancho comparativo

Compara dos opciones, métodos o productos para generar interés en cuál es mejor.
Ejemplo: "Esto vs. esto: cuál rinde más."
Apertura típica: **"¿Cuál es la diferencia entre...?"**

---

Usar como checklist al escribir guiones para las historias/reels de Delika: elegir un gancho por video y validar que el primer segundo lo cumple antes de grabar o renderizar.
